# 프롬프트 신호 점검기

AI에게 질문을 쓰는 사람이 프롬프트를 붙여 넣으면, 그 안의 **신호 8가지**(논문이 직접 실험한 토론 지시·전문가 역할·다수 의견·이미지 구체성 4가지, 선행 연구 기반 풀이 과정·예시·내 의견·열린 추천 4가지)가 답에 주는 영향을 논문 결과로 짚어 주고, 빠진 정보는 채워 주고 불필요한 정보는 제외시켜 **더 구체적인 질문**으로 고치도록 방향을 잡아 주는 앱입니다.

근거 논문: 「프롬프트에 곁들인 신호는 AI의 답을 바꾸는가? — ChatGPT·Gemini·Claude 세 AI에 대한 반복 실험」 (유지원, 2026) — https://gamedh823-cmd.github.io/T10/paper.pdf

## 만든 이유

AI에게 어떻게 묻느냐에 따라 얻는 정보의 질이 달라집니다. 이 앱은 프롬프트의 질을 높여서, 사람들이 AI에게서 더 좋은 품질의 정보를 얻을 수 있게 하려고 만들었습니다. 제 논문(HW10)에서 확인한 "프롬프트에 곁들인 신호가 답을 어떻게 바꾸는가"를 연구실 밖에서도 쓸 수 있게 바꾼 것입니다.

다만 논문이 직접 검증한 것은 신호가 답의 길이·정답률·입장에 주는 영향까지입니다. 채워서 고친 질문이 더 좋은 답을 낸다는 것까지는 검증하지 않았고, 아래 "한계"에 적었습니다.

## 내 컴퓨터에서 실행 (3단계, 설치 없음)

1. ZIP을 풀거나 이 저장소를 내려받아 폴더를 엽니다.
2. `index.html`을 더블클릭합니다. (브라우저에서 열림)
3. 화면의 예시 버튼 하나를 눌러 점검 결과가 나오면 성공입니다.

> 파일로 직접 열면 3번 "AI에게 고친 프롬프트 받기" 버튼은 서버가 허용한 주소가 아니라서 동작하지 않고, 대신 규칙 제안이 보입니다. 1·2번 기능은 인터넷 없이 모두 동작합니다.

## 무엇이 어디에 있나

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면 |
| `core.js` | 신호 감지 규칙(기준선)과 **논문 수치**(표 번호 주석). 수치는 여기에만 있음 |
| `ml.js`, `train/model.js` | 학습한 신호 분류기를 브라우저에서 돌리는 코드와 가중치. 앱은 이것으로 신호를 판단하고 실패하면 규칙을 쓴다 |
| `train/`, `eval/` | 학습 데이터 2000개와 학습 스크립트, 정확도를 재는 라벨 세트·채점 도구·정확도 보고(`eval/report.js`가 화면의 "판정을 얼마나 믿을 수 있나요?" 절의 숫자를 계산) |
| `api/suggest.js` | 3번 기능용 Vercel 서버리스 프록시(Gemini 호출) |
| `tests/*.test.js` | 논문 수치·잘못된 입력(core 31개), 라벨 세트·채점(eval 6개), 학습 모델 연결·약한 신호(ml 10개), 정확도 보고(report 4개) 테스트 |
| `docs/제출문.md` | 확인 방법, AI와 나의 판단 |

## 테스트

```bash
node tests/core.test.js && node tests/eval.test.js && node tests/ml.test.js && node tests/report.test.js
```

Node 18 이상만 있으면 됩니다. 네 파일이 각각 `31개`, `6개`, `10개`, `4개 모두 통과`를 내면 통과입니다.

## 환경 변수 (3번 기능을 직접 배포할 때만)

소스와 화면에는 키가 없습니다. Vercel 프로젝트의 Environment Variables에 이름만 맞춰 넣습니다.

| 이름 | 필수 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | 예 | Google AI Studio에서 발급한 Gemini API 키 |
| `GEMINI_MODEL` | 아니오 | 기본값 `gemini-2.5-flash` |

키가 없거나 서버가 실패해도 앱은 멈추지 않고 규칙 기반 제안만 보여 줍니다. 프록시는 허용 출처 검사, 분당 5회(IP당) 제한, 입력 4000자 제한(화면 점검 한도와 같음), 출력 500토큰 제한을 둡니다.

## 데이터

앱에 들어간 데이터는 논문 본문에 공개된 집계 수치(표 9·12·14·15·18)와, 직접 쓰거나 조합해 만든 합성 학습 문장 2000개로 학습한 모델 가중치입니다. 개인정보가 없고, 입력한 프롬프트는 저장하지 않습니다.

## 한계

- 수치는 계산·세기 문제 10개를 모델·조건당 10회 푼 실험에서 나왔고 포스터 실험은 조건당 5장입니다. 다른 종류의 질문에는 확장할 수 없습니다.
- 신호 감지는 정규식이라 돌려 쓴 표현을 놓치거나 비슷한 말을 잘못 잡을 수 있습니다.
- "정답률이 변하지 않았다"는 결과는 이 실험이 천장 효과(대부분 만점)에 가까워서 한계가 있음을 논문이 밝히고 있습니다.
