## 앱 한 문장

AI에게 질문을 쓰는 사람이 프롬프트를 붙여 넣으면, 이 앱이 그 안의 신호 8가지(토론 지시·전문가 역할·다수 의견·이미지 구체성 4가지는 논문(T10)이 직접 실험, 풀이 과정·예시·내 의견·열린 추천 4가지는 선행 연구 기반)가 답에 주는 영향을 논문 결과로 짚어 주고, 빠진 정보는 채워 주고 불필요한 정보는 제외시켜 더 구체적인 질문으로 고치도록 방향을 잡아 준다.

사용하는 논문 결과: H4 토론은 정답률을 바꾸지 못하고 답을 3~5배 길게 함(표 14·18), H3 전문가 역할은 일관된 효과 없음, H2 다수 의견은 AI마다 달랐음(표 12), H1 구체적 설명은 같은 요청의 결과를 일관되게(색 다양성을 낮게) 함(표 9). "구체적으로 쓸수록 결과가 일관된다"는 H1 관찰이 빠진 정보 안내와 AI 제안의 근거다(채운 질문이 더 좋은 답을 낸다는 것은 논문이 검증하지 않았다).

## 짧은 확인 방법

1. **어디에 무엇이 있나**: URL을 열면 맨 위에 논문 제목과 앱 한 문장이 있고, 그 아래 1번 입력칸, 점검 결과, 2번 AI 선택, 3번 개선 제안이 순서대로 나온다. ZIP이면 압축을 풀고 `index.html`을 연다.
2. **사용자가 할 일 세 가지**
   - ① "예시로 해 보기"의 `토론 지시` 버튼을 누른다. 또는 프롬프트를 직접 붙여 넣고 `점검하기`를 누른다.
   - ② 결과의 8가지 신호 체크리스트와 신호별 카드를 읽고, 규칙 제안(빠진 정보 안내 포함)을 본다.
   - ③ (선택) 맨 아래 `AI에게 고친 프롬프트 받기`를 눌러 진단과 고친 프롬프트를 받는다.
3. **통과 기준**
   - ① 결과 맨 위에 "8가지 신호 중 N가지" 체크리스트가 나오고, 토론 예시에서는 "토론 지시" 카드에 "정답률은 안 바뀌고, 답만 3~5배 길어졌어요"와 ChatGPT 3.4배·Gemini 4.3배·Claude 5.4배가 보인다.
   - ② 규칙 제안에 "질문에 빠진 정보: 상황·대상, 조건·제약 …"처럼 빠진 항목이 나온다. 조건·형식·상황이 다 들어 있는 질문이면 이 줄이 나오지 않는다.
   - ③ 진단 한 줄과 고친 프롬프트가 나뉘어 보인다. 서버 응답이 없으면 안내 문장과 규칙 제안이 보이고 앱은 멈추지 않는다.
   - 잘못된 입력: 빈 칸에서 `점검하기`를 누르면 안내 문장이 나오고 아무것도 깨지지 않는다.
4. 코드 확인: `node tests/core.test.js` → `27개 모두 통과`.

## AI와 나의 판단

① **AI에게 맡긴 일** — 신호 감지 정규식과 논문 수치를 코드로 옮기는 일, 화면과 서버리스 프록시 코드, 테스트 27개, README 작성, 브라우저에서의 동작 점검.

② **내가 직접 판단한 일** — 논문의 어느 결과를 앱으로 만들지(네 가지 실험을 하나로 섞기로 결정), 대상 사용자, 3번 기능에 LLM을 넣을지와 어느 서비스(Gemini 무료 티어)를 쓸지, Vercel 가입과 GitHub 저장소 `T13` 생성, API 키를 Vercel 환경변수에 직접 입력, 공개 범위와 12번 사이트 연결 방식.

③ **AI 제안을 따르지 않은 일** — AI는 "핵심 기능은 키 없이 두고 LLM은 방문자가 자기 키를 넣을 때만 쓰는 선택 기능"으로 줄이자고 제안했는데, 나는 서버리스 프록시로 LLM을 앱에 직접 붙이는 쪽을 택했다. 그래서 키는 Vercel 환경변수에만 두고 남용 방지 제한(출처 검사, 분당 5회, 길이 제한)을 따로 넣었다.
